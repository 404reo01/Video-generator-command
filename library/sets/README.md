# Illustrated sets (decors made from images)

## Purpose
The nicest decors are illustrations, not code. Generate them as images with the same tool as your stickers, drop them here, and `set-from-images` turns them into a set: parallax, camera moves and your character placed behind the desk automatically.

## How to make one
1. Generate two images (prompts below), giving your `neutral` sticker as a style reference:
   - `background.png` — the room, **without** the desk, vertical 9:16 (1080x1920 or larger, same ratio).
   - `foreground.png` — the desk alone on a **transparent** background, same size. Optional: without it, the character stands full-body.
2. Put them in `library/sets/<set-id>/` (e.g. `library/sets/my-office/`).
3. Run `npm run set-from-images -w @mappa/video -- --id <set-id> --description "<one line>" [--pixel]` (`--pixel` for pixel art). Check `library/sets/<set-id>/preview.png`.
4. Claude can then add ambient motion on top (steam, dust, screen glow) as painted layers.

## Prompt — background.png
```
Pixel art illustration, vertical 9:16 (1080x1920), same pixel art style, palette and
lighting as the attached character sprite (cozy, warm, 3/4 view).
<YOUR SCENE, e.g. a cozy home office seen from inside at sunset: a large window on the
upper half showing a city skyline under an orange-pink sky, a hanging lamp, plants,
shelves with books, an orange cat sleeping on the window sill.>
IMPORTANT LAYOUT (background for a talking-head vertical video):
- No desk and no furniture in the bottom 20% of the image: the wall simply continues
  there (a desk is added on top later).
- No person in the image.
- Keep the left third, between 55% and 85% of the height, fairly plain: a character
  stands there.
- Keep the band between 12% and 50% of the height calm, not too detailed: text and
  diagrams are shown over it.
- Nothing important in the right 12% of the image (app buttons cover it).
Crisp pixel art, clean pixels, no text, no watermark, no blur.
```

## Prompt — foreground.png
```
Pixel art, same style and palette as the attached images, transparent background (PNG),
same canvas size (1080x1920). Only <YOUR DESK, e.g. a wooden desk> seen from the front,
at the very bottom of the canvas: its top edge at about 83% of the image height, spanning
the full width. On the desk: <e.g. a monitor on the right showing colourful code lines,
a keyboard, a mouse, a steaming coffee mug, a small plant, a stack of books on the left>.
Objects may rise above the desk edge (monitor, plant) but everything else above the desk
must be fully transparent. No person, no text.
```
If the generator cannot export transparency, cut the background out with a tool such as remove.bg.

## Domain Rules
- Images must be vertical 9:16; foreground and background the same size.
- The desk top is detected as the first row where the foreground covers 80% of the width (objects on the desk cover less); the character is placed so the desk hides the legs.
- Images are drawn 5% larger than the frame, so their outer 2.5% may be cropped: keep nothing important at the very edges.

## Folder Structure
```
sets/
├── README.md          # this file (with the generation prompts)
└── <set-id>/
    ├── background.png # the room
    ├── foreground.png # the desk, transparent above it (optional)
    └── preview.png    # generated by set-from-images
```
