# Mappa

Turns a raw voice recording into an edited 9:16 video: audio -> transcript -> cuts -> clean audio + timeline -> scene plan (shots) -> checks -> Remotion render.
The user-facing entry point is the `/mappa` skill (`.claude/skills/mappa/SKILL.md`).

## Rules
- Read and follow `.claude/developer_guide.md` before any change.
- Talk to the user in French; write everything in the repo in English.
- Read the local `README.md` of a package (or set) before editing it.
- Run `npm run check` before declaring work done.
- The user validates proposals: never apply reviewer suggestions or render a final video unasked.
- Each creator has a profile in `library/channels/` (identity, tastes, lessons learned); the default decor is the one in their profile. Other scenes only on explicit request.

## Commands
- `npm install` — install all workspaces (ffmpeg via `ffmpeg-static`).
- `npm run check` — typecheck + lint + tests; `npm run test:watch` — Vitest in watch mode.
- Audio (per episode): `npm run transcribe|plan-cuts|apply-cuts|timeline -w @mappa/audio -- --episode <slug>`; `npm run make-sfx -w @mappa/audio`.
- Video (per episode): `npm run sync|check-plan|contact-sheet|render-episode -w @mappa/video -- --episode <slug>`; `npm run studio -w @mappa/video`.
- Sprites: `npm run extract|render|stickers -w @mappa/sprites -- --name <character>`.
- Catalog for the director: `npm run catalog -w @mappa/video` (also regenerated by sync).

## Layout
- `packages/shared` — Zod contracts: transcript, cuts, timeline, scene plan, character manifest, music library.
- `packages/audio` — transcription (ElevenLabs), cut planning, ffmpeg, sfx synthesis.
- `packages/sprites` — characters and icons as text grids; sticker packs.
- `packages/video` — Remotion: sets, camera, shots, illustrations, captions, sound, scripts.
- `packages/director` — plan validation rules.
- `library/` — shared by every video: sfx, music + licences, glossary, `stickers/` drop folder, `channels/` creator profiles.
- `episodes/<slug>/` — one folder per video (input audio, transcript, plan, review, renders); git-ignored.
- `tests/` — local experiments, git-ignored; not used by the pipeline.
- Director context for `/mappa`: `.claude/skills/mappa/` — `SKILL.md`, generated `catalog.md`, `references/`; creator profiles in `library/channels/`.

## Secrets
`ELEVENLABS_API_KEY` lives in `.env` (see `.env.example`). Never print, log or commit it.
