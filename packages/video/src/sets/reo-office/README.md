# Set: reo-office

## Purpose
REO's pixel-art home office at sunset: window on the city, sleeping cat, shelves and lamp, wooden desk with monitor, mug and books. Illustrated decor made from images (`library/sets/reo-office/`), generated by `set-from-images`.

## Domain Rules
- Layers back to front: `background` (0.9, image), `room-ambience` (0.9: lamp glow, dust in the window light, the cat's "z"), character, `foreground` (1.06, image), `desk-ambience` (1.06: screen glow, mug steam).
- Ambient positions are measured on the 1080x1920 source images (`ambient.ts`); keep them in sync if the images change.
- Images are drawn on the world enlarged by 5% (`IMAGE_OVERSCAN`) so parallax never shows their edges.
- Character: x 30, bottom 1365, height 600 (desk top at world y 1265).
- Ambient motion (steam, dust, screen glow) can be added as painted layers on top, placed from `library/sets/reo-office/preview.png`.

## Entry Points
- `index.ts` — `reoOffice` set definition.

## Folder Structure
```
reo-office/
├── index.ts   # image layers, ambient layers and character placement
└── ambient.ts # painted motion over the images (glows, dust, z, steam)
```

## What NOT to do
- Do not edit the images here: replace them in `library/sets/reo-office/` and re-run sync.
